# Deep-Learning-Implementations

A collection of hands-on deep learning and NLP/LLM implementations, organized by topic. Each
folder is a self-contained project with its own README, notebook(s), and (where relevant) data.

## Structure

| Folder | Topic |
|--------|-------|
| [`01-ANN`](./01-ANN) | Artificial Neural Networks — fully-connected networks applied to tabular data problems |
| [`02-CNN`](./02-CNN) | Convolutional Neural Networks — image data and classification tasks |
| [`03-NLP`](./03-NLP) | Natural Language Processing — text preprocessing, representations, and sequence models |
| [`04-LLMS`](./04-LLMS) | LLM Applications — retrieval-augmented generation, prompt engineering, and embedding-based search using pretrained models |

Each project folder contains its own notebook and README with details on the approach, models
used, and results — this top-level README is just a map of the repo.
